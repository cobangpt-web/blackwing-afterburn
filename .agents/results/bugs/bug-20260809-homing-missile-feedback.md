# Bug: 유도 미사일이 직선탄처럼 보이는 문제

**Date Reported**: 2026-08-09
**Date Fixed**: 2026-08-09
**Reporter**: User
**Assignee**: Codex
**Severity**: 🟡 MEDIUM
**Status**: ✅ FIXED

## Problem Description

유도 미사일이 표적을 향해 꺾이지 않고 앞으로만 날아가는 것처럼 보였고, 기본 기관포와 외형도 비슷해 무기 구분이 어려웠다.

## Root Cause

- 표적이 비활성화된 뒤 미사일이 새 표적을 찾지 않고 직선으로 계속 이동했다.
- 미사일 렌더링이 두 위치를 잇는 단일 선이라 로켓의 방향과 추진 불꽃이 보이지 않았다.
- 회전·속도 보정 로직이 게임 루프 내부에 직접 있어 동작을 독립적으로 검증할 회귀 테스트가 없었다.

## Fix Applied

- `public/missiles.js`에 표적 재획득과 조향 로직을 분리했다.
- 활성 표적이 사라지면 가장 가까운 적을 다시 추적한다.
- 회전 속도와 속도 보정을 강화해 측면 표적에도 궤적이 보이게 했다.
- 로켓 몸체, 날개, 추진 불꽃, 주황색 트레일을 그려 기본탄과 시각적으로 구분했다.
- 조향·재획득 동작을 `tests/missiles.test.mjs`로 고정했다.
