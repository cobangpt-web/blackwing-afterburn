# 보스 피격 피드백

## 문제

보스에게 미사일이나 주포가 명중해도 실제 체력 감소가 얇은 바에만 반영되어, 플레이 중 타격 여부와 피해량을 확인하기 어려웠다.

## 원인

보스 체력 값은 `updateShots`와 `updateMissiles`에서 정상적으로 감소했지만, 보스 HUD가 작은 단일 바와 짧은 스프라이트 깜빡임만 그렸다. 피격 위치·피해량·현재 체력 숫자를 보여주는 공통 피드백 상태가 없었다.

## 수정

- 보스 HUD는 기존의 얇은 체력 바로 되돌렸다.
- 미사일 명중 시 보스 스프라이트만 짧게 밝게 깜빡이도록 피격 피드백을 단순화했다.
- 미사일·주포·EMP·오메가 계열의 보스 피해는 공통 처리하되 별도 숫자나 문구를 화면에 그리지 않는다.
- 피해량 계산을 `boss-feedback.js`로 분리하고 회귀 테스트를 추가했다.

## 예방

보스 피해를 직접 `enemy.hp -= ...`로 변경하지 않고 공통 피해 처리 함수를 사용해, 새 공격 수단도 동일한 HUD 피드백을 거치도록 유지한다.
